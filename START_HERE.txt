游戏作品集 - Windows 阅读说明

1. 在 ZIP 文件上点击右键，选择“全部解压缩”，再打开文件。
2. 从 README.md 开始阅读；项目介绍汇总位于 docs/PROJECT_EXPERIENCE.md。
3. Markdown 文档和 C# 代码可用 Visual Studio Code 阅读。
4. 本包包含五款游戏的项目说明和 19 份精选代码样例。
5. 本包是源码作品集，没有 Windows EXE、完整 Unity 工程或可直接启动的游戏。
6. 部分代码为阅读节选，依赖与范围已在相应文件及项目说明中标注。
7. 仅阅读无需安装 Node.js；tools/curate.mjs 是可选的完整性校验工具。

文字使用 UTF-8 编码，原始代码文件内容保持不变。
