# 作品集截图清单

第一批准备 15 张：五款游戏各 3 张。优先完成 Enchanted Wetlands 的 3 张，它作为首页特色案例。该游戏再补 2 张机制图后，共 17 张。

下面的文件名是待拍摄材料的命名约定，不表示图片已经存在。采用实际运行画面，记录来源是设备截图还是 Unity Game View。

## Enchanted Wetlands：优先拍摄

| 优先级 | 文件名 | 截什么 | 需要看清的内容 |
| --- | --- | --- | --- |
| 必要 | `01-core-board.png` | 一个清晰的正在游玩棋盘 | 三个基础色光源、完整水道、目标颜色和主要操作区；作为项目封面 |

| 必要 | `03-color-correct.png` | 调整水道、排除第三色后的正确状态 | 所需两色到达目标；优先保留完整棋盘，便于与上一张对照 |
| 补充 | `04-filter-mechanic.png` | 使用滤色石的关卡 | 滤色石的位置、颜色、连接关系及可观察到的过滤结果 |

错误与正确两张使用同一关卡、相同分辨率和取景。先选择实际可以形成干扰色错误状态的关卡，再完成正确连接；需要时从录屏提取通关弹窗出现前的画面，避免弹窗挡住核心棋盘。

以紫色目标为例，可以配文：“红、蓝是所需颜色；黄也进入时不满足目标。调整路径，排除黄色后完成。”配文应对应实际截图中的目标颜色和路径。

如果画面本身不能清楚显示滤色效果，可以补充同一关卡的前后画面或短视频。若拍摄精力有限，先完成前 3 张即可。

项目说明中的身份信息保持为：独立开发、全部开发工作、周期约一周、尚未上线。

## 截图规格与存放

- 格式：保留设备或 Game View 原始分辨率的 PNG；支持时使用至少 1080 像素宽的竖屏画面，较低分辨率不放大冒充原图。
- 取景：保留完整游戏画面，确保目标、玩法区和 HUD 可读；Game View 截图裁掉编辑器外围面板。
- 一致性：同一游戏使用一致的设备比例，对照图保持同一关卡和取景。
- 标注：保留无标注原图；箭头、圈选及说明使用副本，例如 `02-color-mismatch-annotated.png`。
- 文件夹：分别放入 `projects/<游戏目录>/images/`，例如 `projects/Enchanted-Wetlands/images/01-core-board.png`。目前先按此约定准备，上传图片后再添加预览链接。
- 封面：优先复用每款的第 1 张图。主页或关卡地图可作为补充，无需额外制作封面来替代实机画面。
