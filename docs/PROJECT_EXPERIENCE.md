# 项目介绍与个人贡献汇总

## 个人概述

使用 Unity/C# 独立开发休闲手游，负责玩法设计、核心程序、关卡与数值配置、UI 与反馈表现、素材整合、功能调试及发布准备。五款项目均独立承担全部开发职责，使用 Codex 辅助实现与迭代。

已过审作品包括 Dream Repair、Starhook Recovery、Sushi Sprint Sorter 和 Luck Cauldron；Enchanted Wetlands 开发周期约一周，目前尚未上线。审核状态由开发者提供，商店入口补充后可直接附在各项目介绍中。

## Enchanted Wetlands | 独立光路解谜 | 约一周 | 未上线

项目简介：旋转水道，让目标需要的两种颜色汇合，同时排除第三种干扰色，并通过滤色石和锁定石增加路径规划约束。

- 独立负责玩法设计、Unity/C# 开发、关卡配置、UI 反馈和素材整合；使用四方向位表示通道、三个颜色位表示颜色集合，实现连通、混色、滤色与目标精确匹配。
- 分离逻辑模拟与可见光效，复用模拟入口实现预置答案预览，配置 100 关、5 个章节，并组织相关 EditMode 测试。

[项目详情](../projects/Enchanted-Wetlands/README.md) · [完整简历文案](../projects/Enchanted-Wetlands/RESUME.md)

## Dream Repair | 独立手势战斗 | 已过审

项目简介：通过线切和闭合手势施放技能，应对敌人和 Boss，结合关卡推进、成长与修复祝福构成休闲战斗流程。

- 独立负责玩法、程序、UI、素材整合与发布准备；实现时间/距离双阈值轨迹采样、几何手势识别、轨迹平滑和点到线段命中判定，配合战斗反馈与安全区布局。
- 整理 iOS/Android 工程导出及发布资料；历史指定运行时图片集从 109.69 MB 压缩到 81.69 MB，约减少 25.5%，该指标仅覆盖所选图片文件。

[项目详情](../projects/Dream-Repair/README.md)

## Starhook Recovery | 独立网格回收解谜 | 已过审

项目简介：围绕钩索、货物、障碍和目标位置展开网格解谜，通过不同规则组合与无尽关卡提供布局变化。

- 独立负责玩法、程序、规则配置、UI、素材整合和交付；建立坐标、占用和完成条件模型，将网格状态与场景显示分离。
- 实现带种子的关卡生成及规则约束检查，通过有限重试和后备布局处理生成失败，并维护移动端导出配置。

[项目详情](../projects/Starhook-Recovery/README.md)

## Sushi Sprint Sorter | 独立拖拽分拣 | 已过审

项目简介：在三轨道移动队列中拖拽寿司完成分拣，结合局内反馈和局外购买、装备、进度保存。

- 独立负责玩法、程序、UI、规则配置、素材整合及交付；实现射线与屏幕距离结合的选中容错、单对象拖拽、取消恢复及最近轨道吸附。
- 实现钱包、物品所有权、购买装备与本地存档，对无效装备 ID 和类别进行回退；配置交互与持久化 PlayMode 测试，并整理图文官网和隐私页面交付材料。

[项目详情](../projects/Sushi-Sprint-Sorter/README.md)

## Luck Cauldron | 独立炼金成长 | 已过审

项目简介：随机获得材料，通过组合生成炼金产物，并围绕售卖、升级和本地进度形成成长流程。

- 独立负责玩法、程序、数值配置、UI、素材整合及交付；实现权重采样、配方优先级、钱包、升级和本地存档服务。
- 使用协程和缓动组织产物与 UI 反馈，迭代手机/iPad 布局、安全区和 HUD 参数同步，并开展审核设备启动问题的日志排查。

[项目详情](../projects/Luck-Cauldron/README.md)

素材整合与全部开发职责不等同于所有素材均为手绘原创；测试内容指原工程包含的测试，本次没有执行 Unity 回归。量化与历史经历的来源、范围见[资料依据](PROJECT_FACTS.md)。
